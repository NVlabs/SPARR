# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in SPARR, report it
privately to NVIDIA's Product Security Incident Response Team (PSIRT).

Please do not disclose vulnerabilities in public GitHub issues,
pull requests, or discussions.

To submit a report:

- Follow [NVIDIA's vulnerability reporting instructions](https://www.nvidia.com/en-us/security/report-vulnerability/).
- Alternatively, email [psirt@nvidia.com](mailto:psirt@nvidia.com).
  Encrypt your report using [NVIDIA's public PGP key](https://www.nvidia.com/en-us/security/pgp-key/).

Include:

- The project name (SPARR) and affected version, branch, or commit.
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Proof-of-concept code, if available.
- Relevant environment and dependency details.

For general security information, visit [NVIDIA Product Security](https://www.nvidia.com/en-us/security/).
